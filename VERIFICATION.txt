Many-context garden setup, October 3, 2026

Added garden.ps1 and the garden CLI. Defaults: 32 contexts, eight positive
conversation themes, three turns per context, 96 output tokens per turn.
One model is loaded and used sequentially. Joy contexts use the saved
joy-targeted direction; the others use the saved broad-positive direction
with themed prompts. These are not eight independently validated axes.

Each context has an independent history and deterministic seed stream.
The session snapshots its vectors, model revision, themes, and settings.
Completed generations are journaled with flush/fsync. Resume replays those
records, recovers an incomplete final write, and serves unfinished contexts
first. OS file locking prevents concurrent writers to the same session.
Repetition pauses only the affected context. Ctrl+C and a STOP file allow
stopping; rounds 0 continues until stopped or all contexts pause.

All 57 software tests passed with no skips, including the new scheduler,
context/seed isolation, hook cleanup, bounded history, interrupted-journal
recovery, explicit source compatibility/checksum checks, lock exclusivity,
and end-to-end mocked session creation/resume. New sessions start with an
opening prompt before followups; legacy sessions keep their saved schedule
behavior. The opening-prompt adjustment was tested after the live trial.
PowerShell parsing and garden CLI help passed.
